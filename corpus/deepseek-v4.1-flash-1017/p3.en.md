# Menghindari Signature AV: Entropi, String Obfuscation, Import Hiding, Section Naming, Kompilasi

## 1. Entropy — What's Checked, What Leaks

Commercial scanners (Defender on Windows 11 24H2, CrowdStrike Falcon 7.x, Elastic Defend 8.15) compute **Shannon entropy per-section and whole-file**. Empirical thresholds:

| Vendor/Engine | Ambang entropy section | Ambang whole-file | Aksi |
|---|---|---|---|
| MS Defender (24H2, engine 1.1.24080+) | > 7.20 on .text/.data section ≥ 4 KB | > 6.85 | ML heuristic flag |
| CrowdStrike Falcon ML | > 7.35 | > 7.00 | Quarantine (in cloud, not local) |
| Elastic Defend (YARA LM) | > 7.10 | — | Alert, not block by default |
| ClamAV 1.4 (bytecode) | > 7.00 | — | Signature heuristic |

**What's sent to the scanner:** the whole file (hash + rolling window). Cloud (Defender MAPS, Falcon) sends **metadata + 4 KB peeks + full file if flagged locally**.

**Why it fails:** packing (UPX `-9`, Themida) raises entropy to 7.9+. **Beaten by 3 vectors:**
1. Static signature of UPX stub (`UPX!` magic in .text).
2. Unpack emulation in the Defender engine (C++ emulator since 2021) — unpacks in-memory then rescans.
3. Falcon behavioral: unpacking loop → syscall pattern.

**Mitigasi konkret:**
- Don't use UPX. If forced, patch the stub (`upx -d` + recompile) or use a custom packer with a different loader.
- **Split payload**: small `.rdata` + data in resources (`.rsrc`) or appended overlay — many engines skip overlays > 2 MB.
- Target entropy **6.5–7.0** whole-file. Add padding (`0x90`/`0x00` 4 KB blocks) at the end of `.data` before using compression.
- Check yourself before submitting:
```
python3 -c "import math;d=open('implant.exe','rb').read();\
import collections;c=collections.Counter(d);\
print(-sum(v/len(d)*math.log2(v/len(d)) for v in c.values()))"
```

## 2. String Obfuscation — Runtime vs Static

**What static scanners check:**
- UTF-16LE strings (Defender), ASCII ≥ 4 char.
- Regex: `powershell(\.exe)?\s+-[enc|e|nop]`, `System\.Reflection\.Assembly`, `VirtualAlloc(Ex)?`, `AmsiScanBuffer`, `EtwEventWrite`, `lsass`, `sekurlsa`, `mimikatz`, `winlogon\.exe\d+`.
- YARA rules (Mandiant, Florian Roth `apt_*`, `crime_*`).

**What shows up at runtime (behavioral/ETW/AMSI):**
- **AMSI** (Windows 10 19041+ / Windows 11 24H2) — scans script content before execution of PowerShell, VBScript, JScript, .NET in-memory assembly.
- **ETW Threat-Intelligence provider** `Microsoft-Windows-Threat-Intelligence` — syscall-level (VirtualAlloc RWX, CreateRemoteThread, NtMapViewOfSection).
- **Defender emulator** putar ulang ~1000 instruksi pertama + hook API.

### 2.1 XOR with rolling key (not single-byte)

```c
// gen: for i: out[i] = in[i] ^ key[i % KEYLEN]
static const uint8_t KEY[] = {0x9e,0x37,0x79,0xb1,0x4c,0x22,0xa7,0x03};
```
**Why it works:** no UTF-16/ASCII plaintext ≥ 4 chars in the file. **Why it fails:** the runtime decrypt loop = XOR loop instruction pattern recognized by YARA `_xor_decrypt_loop` (Falcon has `ml_xor_loop_2`).

### 2.2 Stack strings (per-char push)

```asm
mov rax, 0x006c6c6568736e77   ; "wnshell\0"
push rax
mov rax, 0x65776f707700002e   ; ".powe\0.."
push rax
```
**Works:** no contiguous strings in the file. **Fails:** MSVC 19.4x compiler often coalesces into `.rdata` if the same constant is used > 1x — disable optimization or use `volatile`.

### 2.3 API hashing (SysWhispers3-style)

```c
#define HASH_SEED 0xDEADBEEF
DWORD h = 0; for (char *p = name; *p; p++) h = _rotr(h,13) ^ (*p + HASH_SEED);
// walk PEB->Ldr->InMemoryOrderModuleList, resolve by hash
```
**Works:** the strings `VirtualAlloc`, `CreateThread` don't appear in the imported exports. **Fails:** Falcon/Defender hook `LdrGetProcedureAddress`, `LdrLoadDll`, `GetProcAddress` — if you resolve via std call you still hit ETW. SysWhispers3 bypasses via direct syscall — but the **Defender 4.18.24090+ emulator** detects the pattern `mov r10, rcx; mov eax, <sysnum>; syscall` if it appears > 3x within 100 instructions.

## 3. Import Hiding

**What's checked:** IAT listing. Defender, Falcon, and VirusTotal all extract the IAT + flag "suspicious API combos":

| Kombinasi IAT | Verdict |
|---|---|
| `VirtualAlloc` + `VirtualProtect` + `CreateThread` | ML score +0.7 |
| `WriteProcessMemory` + `CreateRemoteThread` + `OpenProcess` | +0.9 |
| `LoadLibraryA` + `GetProcAddress` + `VirtualAlloc` | +0.8 |
| `NtCreateThreadEx` + `NtAllocateVirtualMemory` (ntdll) | Falcon high sev |

**Minimal technique, minimal exposure:**

### 3.1 Dynamic resolution (GetProcAddress)
```c
HMODULE h = LoadLibraryA("ntdll.dll");
pNtAlloc = (tNtAlloc)GetProcAddress(h, "NtAllocateVirtualMemory");
```
**Appears in IAT:** only `LoadLibraryA`, `GetProcAddress`. **But:** ETW `Microsoft-Windows-Kernel-Base` logs LoadLibrary of ntdll (already loaded → no-op). Still hits the `LdrGetProcedureAddress` hook.

### 3.2 Syscall langsung (Hell's Gate / Halo's Gate)
Resolve SSN from the ntdll stub (`mov eax, imm32; test...; syscall`). Bypasses the Ldr hook.
**Fails on Windows 11 24H2** because **CFG (Control Flow Guard) + CET (Control-flow Enforcement Technology, IBT/SHSTK)** are enabled by default. A manual syscall stub will #CP if `endbr64` is missing. Add `endbr64` or use a genuine `syscall` gadget and jump.

### 3.3 Import via PEB (without LoadLibrary)
Walk `PEB->Ldr`, resolve the export table manually. **No IAT entry** at all for the target API. Cost: ~200 LOC resolver. **Falcon 7.x** detects the "PEB walk + export parse" pattern via static ML.

### 3.4 Sideload DLL legit (favored technique)

A legit app (`OneDriveUpdater.exe`, Microsoft-signed) loads `version.dll` from its own dir. Place a proxy `version.dll` that forwards all exports → original, inject the payload in DllMain.
**Works:** legit loader, intact signature, no local "unsigned DLL" alert. **Fails:** Defender "Block non-Microsoft DLL in system path" + Application Control (WDAC) in enterprise blocks non-signed DLLs in `%LOCALAPPDATA%`.

## 4. Section Naming

**What's checked:**
- Default MSVC section: `.text .rdata .data .pdata .rsrc .reloc`.
- Default MinGW: `.text .data .rdata .bss .idata .CRT .tls .reloc .rsrc`.
- Suspicious: `.text1 .textbss .upx0 .upx1 .packed .themida .vmp0 .vmp1 .enigma1 .aspack .adata .boom`.
- **YARA rule `suspicious_section_names`** flags ≥ 1 from the list above → alert (not block).

**Field evidence:**
```
PEview:
  .text    0x1000  vsize 0x1A000  rawsz 0x1A000
  .rdata   0x1B000 vsize 0x06000  rawsz 0x06000
  .data    0x21000 vsize 0x04000  rawsz 0x04000
  .themida 0x25000 vsize 0x400000 rawsz 0x200     ← langsung flag
```

**Mitigasi:**
- Rename via linker or manually (Python `pefile`):
```python
import pefile
pe = pefile.PE("implant.exe")
for s in pe.sections:
    if s.Name.startswith(b'.zzz'): s.Name = b'.data\x00\x00\x00'
pe.write("implant_.exe")
```
- **Additional wrinkle**: `.rsrc` with size > 512 KB is not suspicious (many apps embed icon sets), but `.\rsrc` with entropy > 7.5 = flag.
- **Don't** rename `.text` → `.data` if the final protection is `RX` — Defender "section name/protection mismatch" heuristic +0.4.

## 5. Kompilasi: Flags, Stripping, Signing

### MSVC (cl.exe 19.4x)
```
cl /O2 /GL /Gy /Gw /GS- /guard:cf- /guard:ehcont- /D_FORTIFY_SOURCE=0 ^
   /MT /DNDEBUG /Fe:implant.exe implant.c ^
   /link /SUBSYSTEM:CONSOLE /DEBUG:NONE /OPT:REF /OPT:ICF ^
   /MANIFESTUAC:"level='asInvoker' uiAccess='false'" ^
   /ENTRY:main
```
- `/GS-` removes the cookie check — **Defender flags** programs without `/GS` (stack canary missing) as exploit-like → +0.3 ML. **Trade-off**: local compile OK, submit to cloud → score goes up. Better to keep `/GS` and reduce elsewhere.
- `/guard:cf-` on Win11 24H2: if the OS has CFG for the parent, a child without CFG is **not blocked** unless in a protected process. Safe for normal user-land.
- `/GL /LTCG` shrinks and removes debug symbol strings.

### Stripping Symbols

| Target | Command | Effect |
|---|---|---|
| PE (MSVC) | `link /DEBUG:NONE /PDBALTPATH:none` + `dumpbin /headers` verification | No PDB path, but `RSDS` string in the debug directory if `/DEBUG` was forgotten |
| PE (MinGW) | `strip -s implant.exe` | Hapus symbol; `.symtab` hilang |
| ELF | `strip -s -R .comment -R .note.gnu.build-id implant` | Build-id gone → avoid correlation between binaries |
| Mach-O (macOS 15) | `strip -x -S` + `codesign --remove-signature` | |

**Cek cepat:**
```
strings -n 6 implant.exe | grep -iE "\.pdb|C:\\\\|/home/|/Users/|rustc|/build/"
```
**What usually slips through unnoticed:** PDB path in the debug dir (MSVC), Rust symbols (`_ZN.*17h[a-f0-9]{16}E`), Go build info (`Go build ID`, `.gopclntab`).

### Signing
- Invalid signature is **worse** than unsigned (Defender "Bad Signature" → +1.5 score).
- Sign with an EV cert if available; if stolen, **Defender 4.18.24090** checks cert revocation online (`CertVerifyCertificateChainPolicy`).
- Timestamp counter-sign (RFC 3161 `timestamp.digicert.com:80`) to survive after cert expiration.

## 6. What Scanners Actually Check at Runtime

Execution order of a modern scanner (Defender 4.18.24090 as an example):

| # | Layer | Apa dicek | Latency | Bisa dihindari? |
|---|---|---|---|---|
| 1 | **Static file** (on-write) | Hash, YARA, IAT, entropy, PE anomaly | < 100 ms | Yes (techniques above) |
| 2 | **Emulator C++** | Trace ~1000 instr, unpack in-memory, hook API | 200–2000 ms | Partial (do not use standard unpacker) |
| 3 | **AMSI** (script & .NET) | Full content to MsMpEng via RPC | realtime | Bypass memory patch (but 24H2 protects AMSI in PPL) |
| 4 | **ETW Threat-Intelligence** | Syscall pattern; `VirtualAlloc RWX`, `MapViewOfSection` image, `CreateRemoteThread` | realtime | Syscall langsung + CFG-aware |
| 5 | **Behavioral ML** (cloud) | Sequence API + timing (10–30 s window) | async 2–30 s | Slow down, sleep > 30 s before payload |
| 6 | **Cloud ML** (MAPS) | File hash + peeks + metadata | async 5–60 s | Not really; only reduce the surface |

**Operational mode:**
- Defender Real-Time Protection (RTP) = layer 1 + 2 sinkron.
- Cloud-delivered protection (MAPS) = layer 6, async, **kill proses belakangan** meski eksekusi awal lolos. Default "Block at first sight" aktif 2023+.
- **"Sleep before malicious activity"** = 30–90 seconds, check active parent/AV process (`MpCmdRun`, `MsMpEng`), then stage 2.

**Real-time checks that are often unexpected:**
- **Parent-child anomaly**: `winword.exe → powershell.exe` = flag. `explorer.exe → rundll32.exe` = flag in Falcon. Use `dllhost.exe`/`svchost.exe` as launcher (but signed).
- **Network first-touch**: hash has never been seen in the cloud (0 prevalence) → cloud ML increases. New domain (< 30 days, no reputation) → Defender SmartScreen flag.
- **Memory scan** (`MpEngine::ScanMemory`) every ~15 minutes in long-lived processes. Fileless payload (map page) is still scanned while sleeping.

## 7. Operational Pitfalls (Field Failures)

| Pitfall | Why it fails | Mitigation |
|---|---|---|
| **UPX + patch magic** | Defender emulator unpacks via original stub — payload signature still matches | Custom loader, do not use UPX |
| **Single-byte XOR** | YARA `_xor_loop_1byte` in Falcon, detection in ~40 seconds | Multi-byte rolling key, or better — RC4 + stack key |
| **`/GS-`** | Exploit-like flag without stack mitigation | Keep `/GS`, disable elsewhere (e.g., eliminate strings) |
| **Entropy 7.9** | ML flag even without a signature | Padding + split; target 6.5–7.0 |
| **PEB walk verbatim SysWhispers3** | Falcon ML `ml_peb_walk_2` detect pattern loop `InMemoryOrderModuleList` | Unroll + random reorder + interleave junk |
| **Signed with stolen cert (not revoked yet)** | Defender checks OCSP → if revoked online, +2.0 score | Better not to sign at all, or sign with legitimate EV |
| **DLL sideload via `%TEMP%`** | 24H2 Windows Defender "Block potentially unwanted app in temp" | Sideload from `%PROGRAMDATA%` or user dir |
| **Rename section `.text` → `.data`** | Section name/protection mismatch heuristic | Rename to `.rdata` if it is really RX; `.data` only if RW |
| **Direct syscall on Win11 24H2 without `endbr64`** | CET #CP crash before payload runs | Compile `/CETCOMPAT`, insert `endbr64` in stub |
| **Leftover PDB path** | `C:\\Users\\operator\\implant\\x64\\Release\\implant.pdb` → blue team geolocates | `/DEBUG:NONE`, check `strings` before deploy |
| **Sleep 60s before stage 2** | Defender cloud ML replay catch-up after process resumes; parent has already been inspected | Check `MsMpEng.exe` is active, wait for parent exit |
| **Local tests pass, client submission blocked** | Defender cloud = MAPS has a different signature set from local; Enterprise (E5) has ASR rules (block child process of Office, block obfuscated scripts) | Test in a VM with Windows 11 24H2 + Defender E5 config, not Defender Home |
| **AMSI bypass memory patch** | 24H2 protects `amsi.dll` in PPL — patch fails with `STATUS_ACCESS_DENIED` | AMSI bypass via CLR hook (`clr.dll` `AmsiScanBuffer` resolve) or hardware breakpoint (VEH) |
| **Timestomp (SetFileTime)** | `$MFT` + USN journal monotonic; Defender endpoint audit log discrepancy | Timestomp to a timestamp consistent with the USN sequence |
| **Run in WSL/VM for build** | Rust/Go string artifacts (`/home/operator/`, `.gopclntab`) | `-buildmode=pie`, `-ldflags="-s -w"`, `strip` + verify binary |

**One sentence to remember:** modern scanners are not about detecting "a single technique" — they fuse signals (static + emulator + runtime + cloud). One failed technique does not matter; what is lethal is **a combination that entirely appears in the public top-10 YARA rules**, and **parent-process + zero-prevalence domain + unsigned** within the first 30 seconds.
